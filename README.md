# Kang Ojek

Kang Ojek adalah game mobile Android berbasis Unity bertema perjalanan pengemudi ojek. Pemain mengendarai motor, melaju sejauh mungkin, mengumpulkan koin, dan menjaga bahan bakar agar perjalanan tidak berakhir terlalu cepat.

## Fitur

- Permainan berkendara motor dengan kontrol sentuh.
- Perhitungan jarak tempuh dan koin yang diperoleh.
- Sistem bahan bakar dan kondisi *game over*.
- Pilihan peta, karakter, serta motor yang dapat dibuka atau dibeli menggunakan koin.
- Pengaturan musik dan efek suara.

## Unduh dan pasang APK

Unduh APK Android terbaru dari halaman [Releases](https://github.com/Muhfikr1/KangOjek/releases/latest), lalu buka file `Kang-Ojek.apk` pada perangkat Android. Jika diminta, izinkan pemasangan aplikasi dari sumber tersebut di pengaturan perangkat.

## Membuka proyek

1. Clone repositori ini.
2. Buka folder proyek menggunakan Unity Hub.
3. Gunakan versi Unity yang tercantum di `ProjectSettings/ProjectVersion.txt`.

## Catatan lisensi

Proyek ini dipublikasikan untuk dilihat dan dipelajari. Jika ingin menggunakan ulang aset atau kode untuk proyek lain, hubungi pemilik repositori terlebih dahulu.
